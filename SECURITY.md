# Security policy

Report vulnerabilities privately through https://github.com/ysfclc/Locco/security/advisories/new . Do not publish exploit details before coordination.

Treat imported data, source content, model output, ZIPs, dependencies and artifacts as untrusted. Never commit credentials, signing keys, cookies, user datasets or model weights. Never log secrets or private content. Follow docs/security/threat-model.md, secrets-policy.md, signing-policy.md and supply-chain.md. Security-sensitive changes require security review and independent QA.
