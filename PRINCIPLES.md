# Locco principles

1. Locco owns its identity; no donor repository or first use case defines it.
2. Local-first: no mandatory account, paid API, hosted database or cloud model.
3. Native mobile only: Android primary, iOS anticipated. No HTML, web UI, PWA or browser-delivered product.
4. Rust owns domain truth, IDs, invariants and cross-platform contracts; shells own OS lifecycle and UX.
5. Preserve source evidence and provenance before interpretation; never overwrite evidence with AI output.
6. Deterministic code handles parsing, validation, policy, dedupe and state transitions; AI handles bounded semantic ambiguity.
7. Context is scarce: task-specific retrieval, hard budgets, no transcript-as-memory.
8. AI cannot grant permissions, execute arbitrary tools or certify success.
9. External actions require a declared capability, exact payload, authority, appropriate approval and postcondition evidence.
10. Sources, models, storage and bridges are replaceable adapters.
11. No bypass of authentication, CAPTCHA, paywall, anti-bot or OS security.
12. Zero-budget baseline; paid services optional with local/manual fallback.
13. No silent scope creep; consequential changes require ADRs.
14. Design for reversibility; document failure modes and costs.
15. Done means evidence, not a green build alone.
