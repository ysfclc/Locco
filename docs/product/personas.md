# Users and operating context

Primary user: one individual using Locco across work, projects, research and daily digital activity. Initial deployment is personal, Android-first and zero-budget. No multi-user, tenant or SaaS assumptions. iOS is a future personal shell.

Known reference device: Redmi Note 12 Pro 5G, Dimensity 1080, 8 GB RAM and 256 GB storage (user-established baseline). Record the exact Android build, security patch, Android System WebView provider/version and Chrome version at each test. This is one required compatibility/benchmark target, not a claim that Locco supports only this device. Do not assume flagship memory/thermal headroom; establish budgets from physical-device measurements.

UX: one-hand capture, offline-first, resumable tasks, inspectable evidence, uncertainty disclosure and manual alternatives. Core navigation never waits for a model.
