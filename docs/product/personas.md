# Users and operating context

Primary user: one individual using Locco across work, projects, research and daily digital activity. Initial deployment is personal, Android-first and zero-budget. No multi-user/tenant/SaaS assumptions. iOS is a future personal shell.

Known device baseline: mid-range Android, 8 GB RAM, Dimensity-class SoC. Do not assume flagship memory/thermal headroom. Exact model and latency budgets require physical-device measurement.

UX: one-hand capture, offline-first, resumable tasks, inspectable evidence, uncertainty disclosure, manual alternatives; core navigation never waits for a model.
