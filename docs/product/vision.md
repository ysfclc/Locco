# Vision

Locco is a personal, local-first mobile intelligence and action environment. It connects information and capabilities fragmented across websites, apps, files, messages, maps, devices and workflows. It captures information with provenance, builds a navigable model of entities and relationships, supports compact on-device reasoning, and enables controlled actions.

It is not defined by one vertical. Sourcing, research, personal knowledge, operations, automation, development workflows and location intelligence are possible expressions of one engine.

**Acquire → preserve → understand → connect → reason → decide → act → verify → learn.** The user remains the authority.
