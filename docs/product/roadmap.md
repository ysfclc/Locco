# Roadmap

0 Foundation: product, principles, architecture, FFI, Rust workspace, empty Android shell, iOS plan, security, agents, skills, ZIP protocol and CI. Gate: 3 Rust Android ABIs + placeholder APK; docs agree; no product logic.

1 Local kernel: DB, migrations, IDs, evidence, entity graph, events, export/restore. Gate: deterministic/migration/round-trip/offline tests.

2 Acquisition: source contract, share/import, file and visible browser capture. Gate: provenance, dedupe, cancellation, hostile-input tests.

3 Local intelligence: benchmark model/embedding candidates; context compiler, retrieval, schema validation and golden set. Gate: measured latency/RAM and deterministic fallback.

4 Workspace: native navigation, search, entity/evidence views, review queue. Gate: accessibility, adaptive layout, process restoration.

5 Capabilities: typed plans, policy, approvals, idempotency, execution and verification. Gate: threat review and end-to-end proof.

6 Expansion/iOS: new sources/platform only after contract parity and migration plan. No phase starts without prior acceptance evidence.
