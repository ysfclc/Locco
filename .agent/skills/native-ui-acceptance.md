# Skill: Native UI acceptance

When: native UI/navigation/permission change. Preconditions: feature contract and intent states.

Procedure: define loading/content/empty/offline/partial/error/success; test back stack/process restore; touch targets/labels/contrast/font/TalkBack; narrow/expanded windows; reduced motion; AI uncertainty/evidence; exact-payload approval invalidation.

Verify automated UI tests + manual accessibility/device checklist; no success without postcondition.

Failure: state loss, inaccessible control, false confidence or unreviewed action blocks acceptance.
