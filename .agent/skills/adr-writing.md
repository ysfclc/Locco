# Skill: ADR writing

**When:** Any consequential product, module, data, platform, security or dependency decision.

**Preconditions:** Read ADR index, principles, scope and affected docs.

**Procedure:** State status/date/reversal cost; context; one decision; alternatives; constraint-tied rationale; failure/detection; reversal/migration; update index and linked docs.

**Verify:** Reviewer can tell what changed, why, what fails and how to reverse. No conflicting accepted ADR remains.

**Failure:** Missing evidence/alternatives/reversal or implementation disguised as decision; revise before merge.
